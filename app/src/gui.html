指纹抽取 · 连抽采集

  1. 同步账号官网登录后，到顶部「账号 / 同步」同步当前账号。
  2. 选目标模型下方列表 Ctrl 多选、Shift 连选；留空＝按次数抽卡。结果为指纹推测，不是认证。
  3. 设抽取方式按次数抽就填次数；想抽到命中为止，勾选下方「持续抽取」。轮数 1＝快速匹配、2＝交叉参考、3＝一致性检查，只有 3 轮给出标定判定，1–2 轮只显示最接近候选。
  4. 开始连抽选停止条件（命中任意 / 全部各命中一次），点「开始连抽」。验证码由你完成；单轮报错记一笔继续，连续 10 轮失败才自动停。
  5. 收结果候选会话存进「模型归档」，选用后用本地 API 调用。

鹈鹕评分

  1. 同步账号官网登录后，到顶部「账号 / 同步」同步当前账号。
  2. 设次数与间隔填次数（想跑几次填几）；勾无限次就一直跑到点停止；每完成一次等间隔秒数再开始下一次，间隔默认 30 秒。
  3. 评分三档：不评分只画图收图、不调评委；静帧评分只用首帧打分、满分 80、动画压 0、最快，分档 <45 差、45–48 中、49–52 良、≥53 优；静动评分首帧 + 6 帧拼图一起打、满分 100、最久最综合，分档 <60 差、60–65 中、66–72 良、>72 优。评分时分数写进对话名和文件夹名，如静帧 R1-1_51静、动图 R1-1_73，不评分只按序号命名；档位（优/良/中/差）不写进名字，只用来按分数归档。
  4. 开始连抽点「开始连抽」。验证码由你完成；一个对话发完、等图、收图、存好，再建下一个对话；单个对话 600 秒没出图记失败、跳下一个，不卡住整轮。
  5. 收结果图片存到 选妃资料\鹈鹕\日期\，图片名和改名后的对话名一致，方便肉眼比对。
