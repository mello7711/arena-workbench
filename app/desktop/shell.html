固定节点与账号绑定（暂时没修）
?固定代理怎么用查看操作步骤
  1. 把机场订阅填到“订阅地址”，点“读取订阅并导入”；或粘贴节点链接后点“导入节点”。两种方式任选一种。
  2. 在“绑定账号”填写要使用此节点的 Arena 邮箱，再从“节点”中选择一个，点“检测所选节点”。
  3. 检测通过后点“保存固定绑定”，再点“启用固定节点”。未绑定账号会自动分配一个非失败、绑定数量最少的节点并固定保存。
  4. 绑定已打开的账号后，在“账号 / 同步”切换到它以应用新节点，完成官网验证后同步。也可在任务结束后先停用、再启用固定节点以应用当前绑定。

只想沿用 FlClash：不用导入订阅，保持固定节点停用，在下方“统一代理”填本地 HTTP 端口并保存；这时节点由 FlClash 当前选择决定，不是每个账号独享一个节点。

支持 HTTP/SOCKS、常见分享链接、Clash proxies 配置和 HTTPS 订阅。未绑定账号自动选择绑定数量最少的非失败节点，选定后固定。节点测试结果不保证网站一定接受该出口。

?账号 / 同步怎么用：一个账号一间房查看操作步骤
  1. 把每个 Arena 账号想成一间独立房间：切换＝换房间，原账号永远完整留在自己房间，不用去官网退号；各房间的登录与抽卡归档互不相通。
  2. 添加新账号（邮箱验证码或 Google 登录都适用）：在“右侧 Arena 当前登录邮箱”里填新账号邮箱（只填地址，不填密码），点“打开此邮箱的独立登录环境”，右侧官网即变成该账号的全新未登录状态。
  3. 在右侧官网完成登录：邮箱验证码登录，或点“使用 Google 账号登录”选你的谷歌号授权；验证码可在“邮箱”弹窗里取。
  4. 回到本页，确认邮箱一致，点“同步当前登录”＝登记入住；抽卡与本地 API 只认已同步的账号，不点同步 API 不认。
  5. 回旧账号：从“已保存的 Arena 账号”下拉选中，点“切换所选账号”，秒回无需重新登录。切换后右侧偶而显示“登录中/登不上”是页面外观——只要这个房间还留着有效登录，直接点「同步当前登录」即可成功，不必等它。抽卡或 API 任务运行中不能切换。

三种登录方式随意：邮箱验证码 / Google 授权 / 密码。用邮箱验证码登录新账号时，先到「邮箱」弹窗导入该邮箱（否则官网收不到码）。记一句话：「邮箱」是信箱，账号是身份，「同步」是让面板认身份。

先在官网完成登录，再同步到本地 API。同步会核对邮箱，不读取邮箱密码。

导入邮箱只用于收信，不等于 Arena 已登录。每个 Arena 账号保留独立网页登录资料；切换后完成官网登录，再点同步，API 才恢复。抽卡或 API 任务运行时不能切换。

?邮箱怎么用查看操作步骤
  1. 每行粘贴一个已有邮箱，格式见下方示例，再点“导入并加密保存”。这一步不会注册或登录 Arena；它的用途是当“信箱”——给 Arena 账号收验证码。
  2. 在“邮箱账号”里选中账号。有微软 Client ID 和有效刷新令牌时，点“读取收件箱”；只有密码时，点“打开邮箱网页”并自行登录收信。
  3. Arena 需要邮件验证码时，在这里取码，再切回“Arena 官网”填写。拿到邮件不代表 Arena 已登录。
  4. 要让这个 Arena 账号用于抽卡/API：进入“账号 / 同步”，填写同一邮箱，打开独立登录环境，完成官网登录，再点“同步当前登录”。

示例：name@example.com----邮箱密码；微软四字段格式：邮箱----邮箱密码----Client ID----刷新令牌。四字段必须已有对应邮箱的读取授权。

每行一个账号，也支持制表符分隔。重复邮箱更新原记录。密码与令牌仅在本机加密保存。

四字段账号通过微软官方 Graph 接口读取邮件；需要有效授权。仅有密码时使用网页登录。每个邮箱保留独立登录环境。
