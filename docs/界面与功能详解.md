# 界面与功能详解

> 这份文档逐块讲清楚工作台每个区域、每个按钮是干什么的。
> 遇到不会用的地方，从这里查。

## 窗口布局

打开工作台后是一个单窗口，分成左右两块：

```
┌───────────────────────────────────────────────────────────┐
│ Arena 工作台   [管理] [工作区]   邮箱 代理 收起面板 账号/同步 │  ← 顶部栏
├──────────────┬────────────────────────────────────────────┤
│              │                                            │
│   管理面板    │            Arena 官网                      │
│   （左侧）    │            （右侧）                         │
│              │                                            │
│  管理区：     │   登录 / 抽卡 / 对话 / 导入导出             │
│   ·模型归档   │   都在这个真实的网页里                      │
│   ·连抽采集   │                                            │
│              │                                            │
│  工作区：     │                                            │
│   ·隧道与MCP  │                                            │
│   ·冷启动包   │                                            │
│   ·接力       │                                            │
│              │                                            │
└──────────────┴────────────────────────────────────────────┘
                 ↑
            这条竖线可以左右拖动，调面板宽度
```

**关键前提**：右边的官网是**真实的 Arena 页面**，不是模拟的。你在里面登录、对话，
和在浏览器里操作完全一样。工作台只是把它嵌进了窗口，并在左边加了个控制面板。

## 顶部栏按钮

从左到右依次是：

| 按钮 | 作用 |
|---|---|
| **管理** | 左边面板切到「管理区」（抽卡、模型归档） |
| **工作区** | 左边面板切到「工作区」（隧道、冷启动包、接力） |
| **邮箱** + 数字 | 打开邮箱管理弹窗，数字是已导入的邮箱数量 |
| **代理** | 打开代理节点管理弹窗 |
| **收起面板** | 把左边面板整个收起来，窗口变成纯官网 |
| **账号 / 同步** | 账号切换与登录同步 |

## 一、账号 / 同步

点开是个弹窗，做三件事：切账号、加账号、同步登录态。

### 为什么需要独立的「环境」

Arena 的一个账号在浏览器里靠 cookie 认人。如果你在同一个浏览器里切两个号，
cookie 会互相覆盖，导致「切了号但还是登着上一个」。

工作台的做法：**一个账号 = 一个独立的浏览器分区（partition）**。
每个分区的 cookie、缓存、localStorage 完全隔离，互不影响。

所以你有几个号，就有几个互不干扰的小浏览器。

### 操作流程

**加一个新号：**

```
1. 点「账号 / 同步」
2. 填入新账号的邮箱
3. 点「打开独立登录环境」
   → 工作台会为这个邮箱建一个全新的空分区
4. 在右边官网页面登录（输邮箱+密码+验证码）
5. 登录成功后，点「同步当前登录」
   → 把这个分区的登录态保存下来，绑定到这个邮箱名下
```

**切换到已有的号：**

```
1. 点「账号 / 同步」
2. 从下拉框选择目标邮箱
3. 点切换
4. 如果显示「登录中」但进不去，直接点「同步当前登录」
```

> **常见误解**：切换后看到「登录中」不代表失败。只要那个分区里还留着有效的登录态，
> 点一下同步就能恢复，不需要重新输密码。

### 重要限制

- **抽卡或 API 任务运行中不能切换账号**。右侧页面正在被占用，切了会中断任务。
- 每个账号的**模型归档是独立的**。A 号抽到的模型不会出现在 B 号的列表里。
- 账号数量没有硬上限，但每个号都占内存和磁盘（一个分区好几 MB）。

## 二、邮箱

点顶部「邮箱」打开。

### 是干什么的

Arena 注册要邮箱验证码。一个号一个邮箱，号多了以后，**手动登邮箱取验证码是不现实的**。

这个功能让你：

- 一次性导入几百上千个邮箱
- 用的时候直接选中，自动打开对应网页收件箱
- 不用在多个浏览器标签之间来回切

### 邮箱从哪来

闲鱼、淘宝之类的渠道有卖「批量邮箱」的，通常给你一个文本文件，格式是：

```
xxx@outlook.com----password123
yyy@gmail.com----password456
```

或者带更多字段的：

```
xxx@outlook.com----password----client-id----refresh-token
```

### 导入格式

点「导入」，把内容贴进去。**一行一个账号**，支持两种分隔：

| 格式 | 说明 |
|---|---|
| `邮箱----密码` | 最简单的，手动登录用 |
| `邮箱----密码----Client ID----刷新令牌` | 带 OAuth 凭据，能自动取件 |

用 Tab 分隔也行。

**限制**：单次最多 2000 行。

### 导入后会怎样

工作台会：

1. 校验每一行的格式，格式错的会提示是第几行、哪里错
2. 按域名识别服务商（outlook / gmail / qq 等）
3. 保存到加密的凭据库（`mailboxes.dpapi`）
4. 用的时候直接打开对应的网页邮箱

> 凭据库是用 Windows 系统级加密（DPAPI）存的，绑定你这台机器和这个用户。
> **换电脑或重装系统后，这个文件解不开**，需要重新导入。

### 一次完整的注册流程

```
1. 邮箱 → 导入 → 粘贴账号列表
2. 账号/同步 → 填新邮箱 → 打开独立登录环境
3. 右边官网点注册 → 填邮箱
4. 左边邮箱弹窗 → 选中刚才那个邮箱 → 打开收件箱
5. 复制验证码 → 填进官网
6. 注册成功 → 点「同步当前登录」
```

## 三、代理

点顶部「代理」打开。

### 为什么需要

Arena 有风控。**多个账号从同一个 IP 登录、抽卡，很容易被判定为异常。**

代理的作用就是：**让每个账号看起来来自不同的地方。**

### 两种用法

#### 用法一：导入节点，一号一节点

```
1. 代理 → 粘贴节点列表 → 导入
2. 每个账号从下拉框选一个节点 → 绑定
3. 点「检测」验证节点通不通
```

支持的类型：`http` / `https` / `socks5` / `socks4`。

**绑定关系会被持久化**，重启工作台后仍然有效。

#### 用法二：直接指向本机代理（推荐给图省事的人）

如果你本来就在用 Clash / FlClash 这类工具，那就不用费劲导节点了：

```
代理 → 填 http://127.0.0.1:7890 → 保存
```

工作台会直接走你本机的代理客户端，由它负责分流和选节点。

> **好处**：不用维护节点列表，切换机场、换订阅都在你自己的代理软件里做，
> 工作台这边完全不用动。

### 节点检测

点「检测」会依次测试每个节点，显示：

- 是否通
- 出口 IP 是什么
- 延迟多少毫秒

**换号之前先测一下**，避免用了个死节点还以为自己被风控了。

### 注意

- 不绑定任何节点 = 走系统默认网络，**所有账号共用一个出口 IP**
- 代理是按账号绑定的，不是全局的
- 代理配置也存在加密库里（`proxies.dpapi`），同样绑定本机

## 四、收起面板

点顶部「收起面板」，左边整个面板收起来，窗口变成**一个干净的 Arena 官网**。

再点一次（按钮文字会变成「展开面板」）恢复。

**什么时候用：**

- 就想当普通浏览器刷 Arena，不想要侧边栏
- 屏幕小，想给官网更多宽度
- 截图、演示的时候

## 五、管理区

左边切到「管理」页签后的内容。**每个账号一个独立的管理区。**

### 5.1 模型归档

这里列出你抽到的所有会话，按模型分组。

**界面结构：**

```
[搜索框]                     [归档未识别] [全选] [清空]
─────────────────────────────────────────────────────
▸ gpt-6-luna                    可用  41
    ├─ [指纹推测] 会话标题一      [选用] [体检] [复检] [打开]
    └─ [指纹推测] 会话标题二      ...
▸ claude-opus-4.8              可用  12
    └─ ...
▸ 未识别                        3
    └─ ...
```

**每张会话卡片能做什么：**

| 按钮 | 作用 |
|---|---|
| **选用** | 把这个会话设为本地 API 的当前模型 |
| **体检** | 检查这个会话还活着吗（发个探针看有没有响应） |
| **复检** | 重新跑一次指纹识别，确认模型没变 |
| **打开** | 在右侧官网打开这个会话 |
| **归档** | 收进「已归档」，从主列表移走 |
| **解除绑定** | 断开这个会话和 API 的绑定 |

**顶部的批量操作：**

| 按钮 | 作用 |
|---|---|
| **归档未识别** | 把所有识别不出模型的会话一次性归档掉 |
| **全选 / 清空** | 批量选中 |
| **归档所选** | 批量归档 |

**搜索框**：按会话标题或模型名过滤。

### 5.2 连抽采集

抽卡中心。这里是产生模型的地方。

**参数：**

| 参数 | 说明 |
|---|---|
| **抽几张** | 这一轮要抽多少个新会话 |
| **每张几轮** | 每个会话发几轮探针。1 轮快但可能不准，3 轮最准但慢 |
| **目标模型** | 只想要哪些模型。Ctrl / Shift 可以多选 |
| **停止条件** | 「命中任意一个就停」或「全部命中才停」 |
| **持续抽取** | 勾上就不按次数限制，一直抽到命中目标为止 |

**持续抽取必须选目标模型**，否则它不知道什么时候该停。

**抽卡过程：**

```
开始 → 创建新会话 → 发第一轮探针 → 等回答
                            ↓
                   比对指纹库，算出候选模型
                            ↓
              轮数不够？再发一轮，累积证据
                            ↓
         命中目标 → 停下，归档，把会话名改成 [指纹推测] xxx
```

**每轮结束后会弹一个「此任务成功了吗？」的对话框，系统会自动点掉**，
你不用管，也不用手动关。

**单轮失败不会停**，只记一笔继续抽。只有连续失败太多次（说明页面真的挂了）才会停。

### 5.3 指纹用的是什么

抽卡能识别模型，靠的是**数字指纹**技术：

- 向会话发一组精心设计的探针提示（多语言、多类型的数值推理题）
- 从回答里提取数值特征、推理路径、token 偏好
- 和参考库里各模型的「指纹」比对，算相似度
- 相似度超过阈值 → 判定是这个模型

参考库来自开源项目 [Ikaleio/lm-detector](https://github.com/Ikaleio/lm-detector)（MIT）。

**更新按钮**：「检查并更新参考库」会去上游拉最新数据。
上游更新了新模型，点一下就能同步过来，不用等新版本。

> **注意**：这是**闭集统计推断**。意思是在已知模型列表里挑最像的那个，
> 不代表结果 100% 准。参考库的准确率没有经过独立验证，当参考看。

## 六、工作区

左边切到「工作区」页签后的内容。**这一区是个人化的入口**，放日常要用的东西。

### 6.1 打开工作台目录

点一下，用资源管理器打开这个工作台所在的文件夹。

方便你拿冷启动包、看日志、改配置。

### 6.2 隧道与 MCP

三个按钮：

| 按钮 | 作用 |
|---|---|
| **启动** | 启动 SSH 隧道 + MCP 服务 |
| **停止** | 全部停掉 |
| **状态** | 显示当前每个服务的运行状态和 PID |

状态输出长这样：

```
================ Arena Console ================
[RUN ] Tunnel     PID=25928 (VPS 22022)
[RUN ] MCP local  PID=27408 (8765)
[RUN ] MCP fwd    PID=10532
[STOP] ControlBox
```

**这是干什么用的**：让云端的 Arena AI 能操作你这台电脑。
开了之后，你在网页上跟 AI 说「帮我打开某个后台、改个设置」，它真的能做完。

### 6.3 冷启动包

两组、四个按钮：

| 按钮 | 作用 |
|---|---|
| **复制冷启动包** | 把「主包」整段复制到剪贴板 |
| **发送到当前会话** | 直接发到右边官网当前打开的对话里 |
| **复制备用冷启动包** | 把「备用包」复制到剪贴板 |
| **发送备用包到当前会话** | 把备用包发到当前对话 |

**主包和备用包的区别：**

| | 主包（私钥版） | 备用包（公钥版） |
|---|---|---|
| 适用 | 自己的机器，已经配好 SSH 私钥 | 别人的机器，或者私钥不可用时 |
| 原理 | 直接用私钥连 | 走另一条认证路径 |
| 什么时候用 | 日常 | 主包连不上时兜底 |

**怎么用：**

```
1. 点「复制冷启动包」
2. 打开一个全新的 Arena 对话
3. 把整段贴进去，发出去
4. AI 会自己建隧道、接 MCP、开始干活
```

整个过程你什么都不用配。AI 会自己：

- 建 SSH 隧道
- 验证 MCP 端点
- 先发 `initialize`，再发 `tools/list`
- 确认工具都在，然后开始执行任务

**给别人装的时候**：让对方把这份 txt 发给**他自己的 AI**，
AI 会帮他生成本地密钥。文件里的位置都是占位符 `{{...}}`，填自己的就行。

### 6.4 接力

抓取本机 AI 代理的会话，打包成可以交给网页 AI 的交接文本。

**支持的本机 AI：**

| 来源 | 数据位置 |
|---|---|
| ZCode | `~/.zcode/cli/db/db.sqlite` |
| Codex | `~/.codex/sessions` |
| Claude Code | `~/.claude` |
| WorkBuddy | `~/.workbuddy` |

**操作：**

```
1. 点「刷新会话列表」
   → 自动扫描本机，列出所有找到的会话
2. 从下拉框选一个来源（或「全部来源」）
3. 选中某个会话
4. 点「复制接力包」或「发送到当前会话」
```

**为什么有用：**

本地 AI（比如 Codex、Claude Code）干活快，能直接读写文件、跑命令，
但模型能力有天花板。网页 AI 能力强，但每次都要重新解释背景。

接力把两者接起来：

```
本地 AI 干了一段活 → 接力包 → 网页 AI 接着干
```

不用从头讲一遍需求，上下文直接带过去。

**接力包里有什么**：选定的会话记录（默认最近 30 条消息，
每条截断到 800 字符），加上一段说明告诉目标 AI 这份东西从哪来、该怎么用。

### 6.5 导出 / 导入对话

| 按钮 | 作用 |
|---|---|
| **导出当前对话** | 抓取右侧当前页面的对话内容，整理成文本 |
| **导入到新对话** | 把导出的内容送到一个新对话里继续 |

**什么时候用：**

- 对话太长了，想开个新对话但保留上下文
- 想把这个号的对话搬到另一个号
- 想存下来存档

和油猴脚本干的是同一件事，好处是不用装脚本，工作台自带。

### 6.6 鹈鹕测试

点「发送绘画指令」，会给当前模型发一句：

> 请用 SVG 画一只骑自行车的鹈鹕。要求：只输出 `<svg>` 代码本身……

**为什么留这个功能：**

指纹识别要抽好几轮才知道结果，但**让它画张图，你一眼就能感觉出模型成色**。
鹈鹕画得好、结构对、细节在，模型大概率不差。

纯属好玩，不参与任何评分。

## 七、本地 API

工作台本身还跑着一个 OpenAI 兼容接口：

```
http://127.0.0.1:20140/v1
```

| 端点 | 用途 |
|---|---|
| `GET /v1/models` | 列出当前可用的模型 |
| `POST /v1/chat/completions` | 对话，支持流式输出 |

**怎么拿到密钥**：面板「模型归档」区域的连接信息里，点复制才进剪贴板。

**怎么用**：把它当成 OpenAI 的地址，填进任何支持自定义 API 的客户端
（Codex、ZCode、各种第三方前端）。

**但是说实话**：把网页对话包装成 API 再给本地 Agent 调用，**延迟太高，不好用**。
网页加载、打字、等回答，每一步都比原生 API 慢得多。

这个功能保留着，偶尔应急可以用，但日常更推荐直接在工作台里操作。

## 八、常见问题

**Q：点「工作区」没反应 / 面板不动？**
先确认「隧道与MCP」和「主程序」两个目录都在原位，然后关掉工作台重开。

**Q：抽卡时 API 返回「忙碌」？**
抽卡和 API 共用右侧那个官网页面。同一时刻只能干一件事，等抽卡跑完再用 API。

**Q：切换账号后显示「登录中」进不去？**
只要那个分区还留着有效登录态，直接点「同步当前登录」即可，不用重新输密码。

**Q：能同时给几个号抽卡吗？**
不能。抽卡共用右侧页面，一个号抽完切下一个。

**Q：邮箱导入后重启就没了？**
检查 `主程序/.arena-gui/mailboxes.dpapi` 还在不在。这个文件绑定本机用户，
换电脑或重装系统后解不开，需要重新导入。

**Q：冷启动包发出去 AI 没反应？**
确认三样东西都在跑：Windows 本地 MCP（127.0.0.1:8765）、
Windows → VPS 的反向 SSH 隧道、控制框进程。在工作区点「状态」能看到。

**Q：指纹识别的结果准吗？**
当参考看。它是闭集统计推断，在已知模型列表里选最像的，不是确定性判定。
同一个会话多轮的结果和独立参考条件也有差异。
