# 给同学的 AI：装工作台 + 打通电脑（完整交互教程）

> **这份是给 AI 看的，也是给同学看的。**
> 同学只需要做一件事：把下面「★ 开头」的框整段复制，发到你的 AI 对话框里。
> 之后 AI 会一步步带他做，每步都有验证。

# 第一部分：先把工作台装起来（不需要 VPS，不需要花钱）

## 同学要自己做的（AI 做不了）

只有两件，都是双击安装：

| 装什么 | 去哪下 | 关键 |
|---|---|---|
| **Node.js 20 或更高** | https://nodejs.org/ 选 LTS | 一路默认，**装完要重开终端窗口** |
| **Python 3.10 或更高** | https://www.python.org/downloads/ | 安装第一页**必须勾选 `Add Python to PATH`**（默认没勾，不勾后面全报错） |

装完各自验证一下，两条都要有版本号出来：

```powershell
node -v
python --version
```

## ★ 框 1：装工作台（复制整段发给 AI）

```
你是我的安装助手。请帮我在 Windows 上装好 Arena 工作台。
你只能在这台电脑上操作，不要向我要任何密钥或密码。

【背景】仓库地址 https://github.com/mello7711/arena-workbench
它的目录名和程序里写死的路径不一致，所以不能直接装，必须先整理成
下面这个形状，否则「启动隧道」和「发送到当前会话」两个按钮会是坏的。

【目标结构】
<根目录>\
├── 主程序\            ← 仓库的 app/
│   ├── install-windows.ps1
│   └── start-local.ps1
├── 隧道与MCP\          ← 仓库的 bridge/，但里面要分流
│   ├── bin\           ← 脚本全在这里
│   │   ├── svc_ctl.ps1
│   │   ├── relay_pack.py
│   │   ├── desktop_mcp.py
│   │   └── control-box.cjs / control-box.html / selftest.py 等
│   ├── extension\     ← 浏览器扩展
│   ├── requirements.txt / requirements.lock.txt
│   └── 冷启动包-主.txt / 冷启动包-备用.txt
└── 选妃资料\          ← 空目录即可

【第 1 步】确认环境
node -v          必须 v20 以上
python --version 必须 3.10 以上
任一不满足就停下来告诉我，不要继续。

【第 2 步】下载
下载 https://github.com/mello7711/arena-workbench 的 ZIP 到临时目录并解压。
如果电脑上有 git，用 git clone --depth 1 也行。

【第 3 步】整理目录
把解压出来的仓库整理成上面的【目标结构】。重点：
  - app 改名为 主程序
  - bridge 改名为 隧道与MCP，但脚本类文件要放进 bin\ 子目录，
    requirements.txt / requirements.lock.txt / extension 留在 隧道与MCP 根下
  - docs\coldstart\冷启动包-躯壳版-主.txt  →  隧道与MCP\冷启动包-主.txt（去掉「躯壳版」）
  - docs\coldstart\冷启动包-躯壳版-备用.txt →  隧道与MCP\冷启动包-备用.txt
  - 如果仓库里带了 fix-layout.ps1，直接跑它最省事：
      powershell -ExecutionPolicy Bypass -File .\fix-layout.ps1 -Root "<根目录>"

【第 4 步】装 Node 依赖
cd <根目录>\主程序
powershell -ExecutionPolicy Bypass -File .\install-windows.ps1
看到「安装完成」才算成功。中途 [WARN] 可以忽略，[ERROR] 必须解决。

【第 5 步】装 Python 依赖
cd <根目录>\隧道与MCP
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
然后验证：
.\.venv\Scripts\python -c "import mcp,mss,pyautogui,PIL,uvicorn,httpx,pypdf,docx,openpyxl;print('依赖齐了')"
必须打出「依赖齐了」。

【第 6 步】启动
用 start-local.ps1 或 start-gui.bat 启动。注意：**不要重复启动**，
先确认没有已经在跑的实例（否则旧窗口会占着端口，你改了代码也没用）。

【第 7 步】验收，逐条报给我结果
1. 窗口能打开，右边是 Arena 官网
2. 127.0.0.1:20140 有响应
3. 127.0.0.1:8765 在监听
4. 点「工作区」→「状态」，隧道和 MCP 都是 RUN

【要求】
- 每一步失败都要把**原始报错**贴给我，不要只说「失败了」或「可能不行」。
- 不要删除我电脑上的任何文件，除了临时下载目录。
- 装完告诉我根目录的完整路径。
```

# 第二部分：让网页 AI 能操作这台电脑

**这一步的核心问题是：网页里的 AI 在云端，它怎么找到同学家里这台电脑？**

答案是**必须有一条从外网能进来的路**。有两条：

| 路 | 要花钱吗 | 安全性 | 难度 |
|---|---|---|---|
| **A. 买一台 VPS** | 几十元/月 | **好**（只对 VPS 上的一个受限账号开放） | 中等 |
| **B. cloudflared 免费隧道** | 不要钱 | **差**（等于公网挂一个无密码的远程桌面） | 中等，且**必须改代码** |

下面两条都写。**先看完再选。**

---

## 两条路的共同前提（先说清楚，不然后面白做）

**这个 MCP 服务本身没有密码。** 谁连上那个端口，谁就能：

- 读写这台电脑上的任何文件
- 移动鼠标、敲键盘、截图
- 执行任意命令

**所以「谁能连上这个端口」就是唯一的防线。**

- 走 A：只有拿着那对密钥的人能连
- 走 B：**任何知道你那个随机域名的人都能连**

**这就是为什么我推荐 A。**

---

# 路 A：买一台 VPS（推荐）

## A-1 同学要自己做的：买 VPS

| 要求 | 说明 |
|---|---|
| **必须有公网 IP** | 这是唯一硬门槛 |
| 1 核 1 GB 内存 | 够用了 |
| 能 SSH 登录 | 一般默认就有 |
| 系统 | Ubuntu 22.04 / 24.04 都行 |

买哪家都行，几十块一个月。**买的时候记下三样东西**：IP 地址、SSH 端口（通常 22）、root 密码。

## ★ 框 2A：配 VPS（复制整段发给 AI）

```
我要把工作台打通到公网，用一台 VPS 做中转。VPS 信息：
  IP: <这里填 IP>
  SSH 端口: <通常 22>
  root 密码: <这里填，或者我自己登，你只给我命令>

请按顺序带我做完，每一步我确认后你再给下一步。凡是需要我自己登服务器
操作的，把命令整段写出来让我复制，不要让我改。

【第 1 步】在 VPS 上建两个受限账号
sudo useradd -m -s /bin/bash arena_agent
sudo useradd -m -s /bin/bash arena_tunnel
sudo passwd arena_agent
sudo passwd arena_tunnel
（密码我来设，你告诉我设完怎么验证，别问我要密码）

【第 2 步】确认 sshd 允许端口转发
需要 AllowTcpForwarding yes
把检查命令和怎么改告诉我。

【第 3 步】放行端口
反连隧道要占一个端口（我打算用 22022）。
注意：这个端口**不需要对公网开放**，它绑在 VPS 的 127.0.0.1 上。
只要确保 sshd 端口是通的就行。

【第 4 步】在我这台 Windows 上生成密钥
ssh-keygen -t ed25519 -f $env:USERPROFILE\.ssh\arena_agent_ed25519 -C "arena-agent" -N '""'
生成后把 .pub 那一行打出来给我看。
私钥留在我电脑上，绝对不要发到任何地方、不要贴进对话。

【第 5 步】把公钥加到 VPS
告诉我该在 VPS 上执行什么命令，或者告诉我怎么在 VPS 商家的
网页管理面板里填（如果面板能填，优先用面板，更简单）。
限制这个公钥只能做端口转发：
restrict,port-forwarding,permitlisten="127.0.0.1:22022" ssh-ed25519 AAAA...公钥

【第 6 步】写 SSH 配置
在我的 C:\Users\<用户名>\.ssh\config 里加：
Host arena-vps
    HostName <VPS的IP>
    Port <SSH端口>
    User arena_agent
    IdentityFile ~/.ssh/arena_agent_ed25519
    IdentitiesOnly yes
    ServerAliveInterval 15
    ServerAliveCountMax 4
    ExitOnForwardFailure yes

【第 7 步】验证
ssh -F $env:USERPROFILE\.ssh\config arena-vps whoami
必须返回 arena_agent。返回别的或者报错就把原始报错贴给我。

【第 8 步】启动隧道
cd <根目录>\隧道与MCP
powershell -ExecutionPolicy Bypass -File bin\svc_ctl.ps1 -Action start -What all
或者在工作台里点「工作区 → 启动」。

【第 9 步】从 VPS 侧验证（关键）
在 VPS 上执行：
curl -s -o /dev/null -w "%{http_code}\n" -X POST http://127.0.0.1:22022/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"t","version":"1"}}}'
返回 200 才算通。返回 000 或连接被拒就是隧道没起来。

【第 10 步】发给网页 AI
让我把「冷启动包-主.txt」发给网页里的 AI。
这份包里有私钥，只能发给我自己信任的对话，不要发到别处。

【失败时】
每一步失败都要贴原始报错。不要说「可能不行」「我没有权限」，
先跑命令，拿输出说话。
```

## 他装完之后，网页 AI 那边怎么接上

**★ 框 3：这段发给那个要干活的网页 AI**

```
我的电脑已经通过 SSH 反向隧道暴露在 VPS 上，隧道地址是
127.0.0.1:<端口>，MCP 路径是 /mcp。

请按顺序跑这四条，每条都贴原始输出，不要总结、不要下结论：

1. ssh -F ~/.ssh/config arena-vps whoami
2. P=22022; echo "port=$P"
3. curl -s -m 8 -X POST http://127.0.0.1:$P/mcp \

4. 调 tools/list（注意：必须先 initialize 再 tools/list，直接发 tools/list 会超时）

判读：
- 第 1 条返回 arena_agent → 能登进 VPS
- 第 3 条返回 JSON 里有 arena-desktop → MCP 握手成功
- 第 4 条数出 36 个工具 → 全通了

任何一条报错，把原始报错整段贴给我。
如果你在没有跑这些命令的情况下就说「我无法访问你的电脑」，
请先跑一遍再下结论。
```

# 路 B：cloudflared 免费隧道（不推荐，但能跑）

## 为什么我把它排在后面

我实测过这台机器上的 MCP：

```
mcp 1.26.0 / server.py 第 178 行
if transport_security is None and host in ("127.0.0.1","localhost","::1"):
    allowed_hosts = ["127.0.0.1:*", "localhost:*", "[::1]:*"]
```

**cloudflared 转发进来时带的是 `Host: xxx.trycloudflare.com`，不在白名单里，直接 403。**

所以走这条路**必须改代码**，把域名加进白名单。

**改完之后的问题**：MCP 没有鉴权，任何知道那个域名的人都能控制这台电脑。而 trycloudflare 的免费域名虽然是随机的，但**不能当作密码**。

**如果你还是要走**，下面是完整流程。**先想清楚这个风险。**

## ★ 框 2B：配 cloudflared（复制整段发给 AI）

```
我想用 cloudflared 免费隧道把这台电脑的 MCP 暴露给网页 AI。
请按顺序做，每一步失败都贴原始报错。

【前提确认】
我知道这个方案的风险：MCP 本身没有鉴权，任何知道隧道域名的人
都能读写我的文件、控制我的鼠标键盘。请在开始前再提醒我一次，
我确认后你再继续。

【第 1 步】装 cloudflared
winget install --id Cloudflare.cloudflared
或者去 GitHub 下 cloudflared-windows-amd64.exe。
装完 cloudflared --version 要有版本号。

【第 2 步】改 MCP 的 Host 白名单（这是必须的，不改一定 403）
编辑 <根目录>\隧道与MCP\bin\desktop_mcp.py，
找到 FastMCP(...) 那一行（大约第 67 行），改成：

from mcp.server.transport_security import TransportSecuritySettings
server = FastMCP(
    "arena-desktop", host="127.0.0.1", port=PORT,
    stateless_http=True, json_response=True, lifespan=_lifespan,
    transport_security=TransportSecuritySettings(
        enable_dns_rebinding_protection=True,
        allowed_hosts=["127.0.0.1:*", "localhost:*", "[::1]:*", "*.trycloudflare.com"],
    ),
)

改完先备份原文件，再改。

【第 3 步】重启 MCP
先停掉旧的 MCP 进程（确认端口释放），再重新启动。
注意不要重复启动多个实例。

【第 4 步】起隧道
cloudflared tunnel --url http://127.0.0.1:8765
它会打印一个 https://xxxx-xxxx.trycloudflare.com 的地址，记下来。

【第 5 步】自己先验证一遍（不要直接给 AI）
curl -s -o /dev/null -w "%{http_code}\n" -X POST https://<那个地址>/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"t","version":"1"}}}'
返回 200 才算通。

【第 6 步】把地址发给网页 AI，让它连 /mcp

【第 7 步】用完必须关
关掉 cloudflared 窗口，或者 taskkill。隧道开着就是门开着。
免费隧道每次重启地址会变，这是正常的。

【安全提醒】
在隧道开着的时候，不要在这台电脑上登录重要账号、不要开网银。
```

# 第四部分：装完之后怎么用

## 验证清单（缺一条就等于没通）

```powershell
# 1. 主窗口在跑
Get-Process electron

# 2. 后端在跑
curl http://127.0.0.1:20140/health

# 3. MCP 在监听
Get-NetTCPConnection -LocalPort 8765 -State Listen

# 4. 隧道在跑（路 A）
ssh -F $env:USERPROFILE\.ssh\config arena-vps whoami
```

## 日常怎么用

打开工作台 →「工作区」：

| 按钮 | 干什么 |
|---|---|
| 启动 / 停止 / 状态 | 管隧道和 MCP |
| 发送到当前会话 | 把冷启动包发给右边对话框里的 AI |
| 刷新会话列表 | 列出本机的 AI 会话（ZCode/Codex/WorkBuddy） |
| 复制接力包 | 把某个会话打包，粘给网页 AI 接着做 |
| 导出当前对话 | 导出成一个 json 文件 |
| 导入到新对话 | 把导出的记录搬进新对话 |

## 最容易踩的五个坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 按钮没反应 / 报「未找到打通教程」 | 目录没按目标结构整理 | 跑 fix-layout.ps1 |
| 改了代码没生效 | 旧实例还占着端口 | 先全部关掉，再启动一次 |
| `python` 不是内部命令 | 装 Python 时没勾 Add to PATH | 重装，勾上 |
| `ssh` 报 Permission denied | 公钥没贴对，或权限太宽 | 重贴公钥，`chmod 600` 私钥 |
| AI 说「我连不上」但没贴报错 | 它没真测 | 让它先跑命令再说 |
